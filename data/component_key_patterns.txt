# Up to game 0.221 an item lying in the world stored its ItemData as separate
# keys (ItemDrop.SaveToZDO). Game 1.0 packs them into one `itemData` byte
# array and only reads the old keys in ZDOMan.ConvertInventories, which is
# not a component, so the generated table no longer attributes them to
# ItemDrop. Every save from before 1.0 still carries them on every loose
# item; they stay ItemDrop's here.
